Download Moguri

Moguri is an alpha for Macs with Apple silicon. Release builds are ad-hoc signed and not notarized by Apple, so the first launch needs one extra step in System Settings.

{{DOWNLOADS}}

Supported platforms

PlatformStatus
macOS on Apple silicon (arm64)Alpha. The only platform with release builds.
macOS on IntelNot supported. There are no Intel builds.
LinuxNo release builds. Contributors can run part of the test suite on Linux, which isn't release qualification.
WindowsNot supported.

You also need an account with a supported model provider, such as GitHub Copilot, or a local model you configure yourself. Moguri doesn't include a model. The Sandbox environment installs its own pinned runtime through a reviewed setup, and the Remote environment needs an SSH machine you control. Both are optional.

Release files

Every release publishes the same five files on GitHub Releases. Download the DMG and SHA256SUMS from the same release.

FilePurpose
Moguri-<version>-macos-arm64.dmgThe disk image you install from.
SHA256SUMSSHA-256 checksums for every file in the release.
Moguri-<version>-macos-arm64.zipThe archive the in-app updater downloads.
Moguri-<version>-macos-arm64.manifest.jsonThe updater's integrity manifest for the ZIP.
Moguri-<version>-provenance.jsonThe exact source commit and each file's SHA-256.

The release workflow checks that the published files are exactly the files uploaded for that tag. It doesn't prove the binaries rebuild bit for bit from source. Releasing explains what each check proves.

Verify the download

In the folder that contains both files, run:

shasum -a 256 --check --ignore-missing SHA256SUMS

It must print OK for the DMG. Don't open a file that fails this check.

Open it the first time

  1. Open the DMG and drag Moguri onto Applications.
  2. Open Moguri from Applications. macOS blocks the first launch because the app isn't notarized.
  3. Only if the checksum check passed: open System Settings > Privacy & Security, scroll down and click Open Anyway, then confirm Open.

This follows Apple's guidance for opening apps that aren't notarized and saves an exception for this app only. Don't turn off Gatekeeper. If macOS says the app is damaged instead of offering Open Anyway, read macOS launch troubleshooting.

After the first launch, sign in to a model provider and send your first prompt. Getting started walks through it, and the installation guide covers the command line tool, data location and removal.

Updates

By default, Moguri checks GitHub Releases at startup and every four hours. It verifies the updater ZIP against the release's manifest and stages it, and you confirm the install and restart. Public releases need no token. You can also update by hand: quit Moguri, verify the new DMG and replace the app in Applications.

Upgrades migrate local data forward on first start, and you can't go back to an older version afterward.

Build from source

Moguri's source repository isn't public yet, so there's no public way to build it. When it opens, the development setup describes the toolchain and commands. Moguri is licensed under the MIT License.
