# moguri.synctune.it

The [Moguri website](https://moguri.synctune.it), a Synctune project: landing
page, downloads, user guide and developer docs. Plain HTML, CSS and JavaScript
with no runtime dependencies or tracking.

```sh
npm ci --ignore-scripts
npm run dev        # preview at http://127.0.0.1:4173
npm test           # build and static checks
```

- [Website development, sync and deployment](docs/development.md)
- [Site-written task guides](docs/usage/)
- [Moguri documents published on the site](vendor/moguri/) (synced, don't edit)
- [Moguri on GitHub](https://github.com/moguri-dev)
